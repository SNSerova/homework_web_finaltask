Git

  • git init - инициализация нового репозитория в текущей директории.
  • git clone - клонирование удаленного репозитория на локальный компьютер.
  • git add - добавление файлов в индекс (staging area) перед коммитом.
  • git commit - фиксация внесеннызх изменений в репозиторий (измененные файлы, отслеживаемые файлы и т.д.).
  • git status - отображение текущего состония репозитория (измененные файлы, отслеживаемые файлы и т.д.).
  • git log - просмотр истории ккоммитов.
  • git puch - отправка локальных изменений в удаленный репозиторий.
  • git pull - получение изменений из удаленного репозитория и слияние их с локальной версией.
