Git - cистема контроля версий

Начало работы

  • git init - Создаёт новый репозиторий в текущей папке
  • git clone - Клонирует удалённый репозиторий
  • git config - Настраивает параметры Git (имя, email и т.д.)

Основные операции с файлами

  • git add - Добавляет файлы в индекс
  • git add <файл> - Добавляет файлы в индекс (staging)
  • git commit - Фиксирует изменения в репозитории
  • git status - Показывает состояние рабочей директории и индекса
  • git add . - Добавляет все изменения
  • git commit -m "сообщение" - Создаёт коммит
  • git commit --amend - Изменяет последний коммит
  • git rm <файл> - Удаляет файл из репозитория
  • git mv <старый> <новый> - Переименовывает/перемещает файл
  • git log - Показывает историю коммитов
  • git diff - Показывает изменения между коммитами, ветками и т.д.

Ветки

  • git branch - Список веток
  • git branch <имя> - Создаёт новую ветку
  • git branch -d <имя> - Удаляет ветку
  • git checkout <ветка> - Переключается на ветку
  • git checkout -b <ветка> - Создаёт и сразу переключается

Удалённые репозитории

  • git remote -v - Показывает удалённые репозитории
  • git remote add origin - Добавляет удалённый репозиторий
  • git fetch - Скачивает изменения без слияния
  • git pull - Скачивает и сливает изменения
  • git push - Отправляет коммиты на удалённый репозиторий
  • git push -u origin <ветка> - Первый пуш ветки с привязкой
