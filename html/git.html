Git

  • git init - создает новый локальный Git-репозиторий.
  • git clone - скачивает существующий удаленный репозиторий на ваш компьютер.
  • git status - показывает текущее состояние проекта (какие файлы изменены, добавлены или готовы к коммиту).
  • git add. - добавляет все измененные и новые файлы в индекс (подготавливает к сохранению).
  • git commit -m "Сообщение" - сохраняет проиндексированные изменения.
  • git remote add origin - связывает локальный репозиторий с удаленным на сервере.
  • git pull - скачивает изменения с удаленного сервера на ваш компьютер.
  • git push - выгрузка локальных коммитов на удаленный сервер.
  • git branch - показывает список всех локальных веток.
  • git checkout "имя ветки" - переключение между ветками.
  • git log - показывает историю всех коммитов в хронологическом порядке.
