Git

Работа с репозитарием

  • git status - Отображение текущего состояния файлов в рабочем каталоге
  • git add — Добавление файлов в индекс.
  • git clone — Создание локальной копии удалённого репозитория.

Работа с ветвями

  • git branch — Создание ветки.
  • git checkout — Переключение с одной ветки на другую, создание ветки и мгновенное переключение на нее.

Синхронизация

  • git pull — Получение последних изменений из удалённого репозитория и объединение их с локальным репозиторием.
  • git push — загрузка локальных коммитов в удалённый репозиторий.-

Коммиты

  • git commit -m «Описание коммита» — Создание коммита с подготовленными изменениями.
